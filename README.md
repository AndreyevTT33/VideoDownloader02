# 视频下载器 (HLS/m3u8) – 加密版

针对使用 `eval(function(p,a,c,k,e,d){...})` 混淆及 AES‑128‑CBC 加密的网站，提供一键提取并下载受保护视频的工具。

---

## ✨ 功能特点

- **自动解密** – 支持 AES‑128‑CBC 加密的 HLS 流，解析 `#EXT‑X‑KEY` 并完成解密合并。
- **混淆代码执行** – 自动运行网页中隐藏的 `eval(...)` 打包脚本，获取真实 m3u8 地址。
- **专门适配 Missav** – 等待全局变量 `source842` 就绪，优先从已知变量中提取链接。
- **多级提取策略**  
  - 直接读取 `window.source842`、`source1280`、`f` 等常见变量  
  - 手动执行页面中遗留的 `eval` 块  
  - 遍历老版 `flashvars_` 对象  
  - 正则匹配 `videoUrl` 字段  
  - 降级到 `<video>` 标签 `src`  
- **Cookie 管理**  
  - 自动保存 / 加载本地 Cookie（首次需手动登录一次）  
  - 支持手动粘贴 Cookie 字符串（适用于无法自动登录的场景）
- **图形界面 (Tkinter)** – 简洁易用，实时显示下载进度。
- **重试与节流** – 每个片段最多重试 4 次，429 状态码自动退避，并模拟观看间隔防止频率限制。

Python 3.7 及以上（推荐 3.9+）

## 🚀 使用方法

### 1. 启动程序
保存脚本为 `video_downloader_missav.py`，运行：
```bash
python video_downloader_missav.py
```

### 2. 界面说明

| 组件 | 说明 |
|------|------|
| **视频页面地址** | 输入 Missav 或其他类似网站的播放页 URL |
| **保存到** | 下载文件保存目录，默认为 `./downloads` |
| **Cookie 来源** | 选择“使用本地保存的 Cookie”或“手动粘贴 Cookie 字符串” |
| **Cookie 字符串** | 粘贴模式时填写，格式：`key1=value1; key2=value2` |
| **重置本地 Cookie** | 删除已保存的 Cookie，下次需重新登录 |
| **开始下载** | 启动自动化流程 |

### 3. 首次使用（自动登录）
1. 保持 “使用本地保存的 Cookie” 选中。
2. 输入目标视频页 URL，点击 **开始下载**。
3. 在弹出的 Chrome 窗口中手动完成登录（若需要）。
4. 登录成功后，回到程序提示框点击 **确定**。
5. 程序自动保存 Cookie，之后同域名无需重复登录。

### 4. 使用手动 Cookie
1. 选择 “手动粘贴 Cookie 字符串”。
2. 在浏览器开发者工具（F12 → Application → Cookies）中复制所需 Cookie，整理为 `name=value; name2=value2` 格式。
3. 粘贴到文本框中，点击下载即可。

### 5. 下载过程
- 浏览器自动加载页面，等待加密变量出现。
- 提取 m3u8 链接，自动解析主播放列表（master playlist）并选取第一个子流（**无清晰度选择**）。
- 若视频加密，自动下载密钥并解密。
- 临时 TS 片段下载后合并为 `video_output.mp4`，临时文件自动清理。

## 🔍 针对 Missav 的特殊处理

### 为什么叫 “加密版”
某些网站的视频地址经过双重保护：
1. **代码混淆** – m3u8 链接隐藏在 `eval(function(p,a,c,k,e,d){...})` 中，执行后才会写入 `window.source842` 等变量。
2. **AES‑128 加密** – 所有 `.ts` 片段使用 CBC 模式加密，必须用 m3u8 内提供的密钥实时解密。

本工具通过 **Selenium 执行页面中的 eval 块** 确保变量定义，再直接读取 `source842`，同时支持自动解密，专为此类场景设计。

### 与清晰度选择版的区别
- 本版本 **无清晰度选择**，遇到多码率播放列表时自动下载第一个流（通常是默认分辨率）。
- 如果你需要手动选择 720p / 1080p 等清晰度，请使用 **清晰度选择版**（带分辨率下拉框的版本）。

## ⚠️ 注意事项

- **法律合规**：请仅下载您拥有合法权限的内容，遵守网站服务条款及当地法律。
- **链接时效**：部分 m3u8 地址会很快过期，请尽快开始下载。
- **Chrome 版本匹配**：浏览器与驱动版本必须一致，否则驱动无法启动。
- **网络稳定性**：下载大文件时若网络中断需重新开始（无断点续传）。片段级重试可应对短暂波动。
- **变量名变化**：若网站将 `source842` 改为其他名称，程序会尝试备用策略，但极端情况下可能需要修改代码中硬编码的变量列表。

## ❓ 常见问题

### Q: 启动报错 “chromedriver executable needs to be in PATH”
**A:** ChromeDriver 未正确配置。请下载与 Chrome 版本匹配的驱动，并将其路径加入系统环境变量，或直接放到脚本所在目录。

### Q: 浏览器打开后一直不动，或提取不到视频链接
**A:** 可能原因：
- 网站结构调整，`source842` 等变量已更名。尝试启用 “手动粘贴 Cookie” 模式，观察页面是否正常播放。
- 页面加载时间过长，可适当增加 `WebDriverWait` 的等待时间。
- 检查 Cookie 是否有效（尤其是登录状态）。

### Q: 下载的视频只有画面没有声音？
**A:** 部分网站音视频分离存储。本工具当前只下载单一的 m3u8 视频流，若遇到音画分离，需要额外下载音频并手动合并。

### Q: 我想下载其他分辨率怎么办？
**A:** 本版本不支持分辨率选择。如需选择清晰度，请改用 **清晰度选择版**(videodownloader01)，它提供了分辨率下拉框和完整的 variant 选择逻辑。
